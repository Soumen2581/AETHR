AETHR — Physical Resonance Engine (ixmuk)

INSTALL
=======
Run AETHR-x.x.x-Windows.exe and follow the wizard.

The installer places:
  • AETHR.exe            → %ProgramFiles%\AETHR\
  • AETHR.vst3           → %CommonProgramFiles%\VST3\AETHR.vst3\

Rescan plugins in your DAW after installing.

USER PRESETS
============
User .aethr presets are stored under your AppData folder and are not removed
by uninstall or upgrades.

UNINSTALL
=========
Settings → Apps → AETHR → Uninstall
(or use the Start Menu uninstaller)

Signing status is recorded in PACKAGING_STATUS.txt next to this installer when
built via CI.
